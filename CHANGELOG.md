### Brand Identity — Riznexia Rebrand + App-Wide Theming Fix

- **Added:** Real riznexia.com brand applied throughout `apps/admin-web` — navy/gold color tokens re-derived from the marketing site's own compiled CSS (`--color-accent: #c99a3e`/`#d9b565` light/dark, full palette in `app/globals.css`), a new `--color-accent-foreground` token (`#16223a`) so gold-background elements get correct dark-navy text instead of the old white, `Sora` as a distinct display font for headings, and the real logo/icon assets (`public/brand/riznexia-logo.png`, `riznexia-mark.png`, `app/icon.png`, `app/apple-icon.png`) replacing the placeholder wordmark via a new `src/components/layout/logo.tsx`.
- **Fixed (critical, app-wide, pre-existing):** every themed color in the app — across all of F1-F10, not just this rebrand — was silently invisible in a real browser. The installed Tailwind v4 (`4.3.3`) requires CSS-custom-property arbitrary values to use parentheses (`bg-(--color-accent)`), auto-wrapping in `var(...)`; this codebase was written entirely in the Tailwind v3 bracket spelling (`bg-[--color-accent]`), which v4 instead treats as a literal, unwrapped value — compiling to invalid CSS (`background-color: --color-accent;`) that the browser silently drops. Found via a real-browser computed-style check after ruling out caching/stale-tab causes; confirmed by inspecting the actual served CSS. Fixed by converting all 126 affected files across `apps/admin-web` and `packages/ui` (every `bg-`/`text-`/`border-`/`ring-`/`ring-offset-[--color-*]` usage, including compound/variant forms) to the correct `(--color-*)` syntax. This is almost certainly the real cause behind "the UI has zero design" — the design system was correct, it just never rendered.
- **Docs:** DECISIONS.md D-185 (brand tokens/logo/font), D-186 (the Tailwind syntax bug and its fix).
- **Tests:** No new tests — a class-string delimiter change, not a behavioral one. Full `@riznexia/ui` (40 tests) and `@riznexia/admin-web` (338 tests) suites plus `tsc --noEmit` re-run clean. Verified live in a browser: computed styles resolve to the exact intended hex values in both dark and light mode, across Dashboard, Leads, and Sales CRM.
- **Scope:** Visual/theming only — no component logic, no API calls, no permissions, no routes changed.
