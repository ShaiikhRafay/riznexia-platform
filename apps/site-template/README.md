# @riznexia/site-template

Intentionally empty for now.

This will hold the base Next.js template(s) the **Website Generator Agent** ([Doc 20 §11](../../docs/20-ai-agents-architecture.md#11-agent-8--website-generator)) copies and populates per lead before pushing to that demo's own GitHub repo. It is **not deployed from this monorepo** — each generated site is deployed independently (Doc 04 §6).

Category templates (`restaurant-default`, `clinic-default`, etc.) are Module M4 work (Doc 21) — deliberately not scaffolded yet, since template content is business logic, not tooling.
