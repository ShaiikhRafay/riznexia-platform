# @riznexia/ui

Shared, themeable component library for the internal dashboard only (not the generated demo sites, which have their own theme system — Doc 17 §1). Built on Tailwind + shadcn/ui + Radix primitives. Currently empty scaffolding; components are added via shadcn's copy-in model as each screen module needs them, per [Doc 17 §6](../../docs/17-ui-ux-wireframes.md#6-component-library-approach).
